# Onyinye Achomadu — Portfolio

Personal portfolio of Onyinye Achomadu, a full-stack and Web3 developer based in Lagos, Nigeria.

Built with Vue 3 (`<script setup>`) and Vite. Features a dark/light theme that follows the system preference and remembers your choice.

## Sections

- **Home** — overview, experience stats and core skills
- **Projects** — client and personal work (MealPort, Ngbuka, CredNow, Bloomrydes, Web3 DApps and more)
- **Tech Stack** — backend, frontend and blockchain tooling
- **Tools** — day-to-day development tools
- **Contact** — email, phone and availability

## Running locally

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build into dist/
npm run preview  # preview the production build
```

## Project structure

```
index.html        page shell, SEO / social meta tags
src/App.vue       the whole site: layout, content data and styles
public/           profile photos, logo and project screenshots (public/projects/)
```

To add a project, append an entry to the `projects` array in `src/App.vue` and drop an 800px-wide screenshot into `public/projects/`.
